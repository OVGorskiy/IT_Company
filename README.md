# Демонстрационная база, выполненная в ходе обучения

## Реализованные возможности

### Документы
  
  Реализованно взаимодействие с регистрами бухгалтерии, накопления и расчета. Связаны последовательностью документы Реализация и Поступление товаров и услуг

### Справочники
 
  В справочнике Сотрудники реализована идентификация пользователей с использованием пароля и идентификатора

### Отчеты

  Добавлены базовые отчеты на основании данных из регистров
  
### Управление доступом

  Добавлены профили: Администратор, Менеджер контрагентов, Мендежер сотрудников.

### Бизнес-процессы

  Реализован бизнес-процесс "Поручение", с произвольными задачами
